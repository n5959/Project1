Rebuilding the Avenue Building Corporation Website

A rebuild of avenuegroup.ca as a modern, responsive site that keeps Avenue's original colour scheme.

Challenge

The existing site needed a complete modernisation without losing the company's green colour identity, and it had to stay simple enough to add new jobsites by hand.

Solution

I rebuilt the Avenue website in VS Code using HTML, CSS and JavaScript, and built three design versions with the same content and colours but different layouts.

Results

  • Three layout directions to compare.
  • Original Avenue colour scheme kept in every version.
  • New jobsites can be added directly in HTML.
